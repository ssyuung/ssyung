# dataset — 개발용 데이터

DB와 NEIS API 없이 개발하기 위한 파일이다. 출처에 따라 폴더를 나눈다.

| 폴더 | 무엇 | 나중에 바뀌는 곳 | 읽는 코드 |
|---|---|---|---|
| `api/<학교>/` | **외부 API로 가져올 정보.** NEIS 응답 형식 그대로 둔다. 교사가 고치지 않는다 | NEIS 오픈API (`NeisSource`) | `packages/school-data` `FileSource` |
| `db/<학교>/` | **DB에 저장될 정보.** 교사가 화면(추가·설정 버튼)에서 만들고 고치는 것 | Supabase (`SupabaseRepository`) | `packages/repository` `JsonRepository` |

## api/서울개포초등학교

| 파일 | 내용 |
|---|---|
| `학급정보.json` | NEIS 학급정보 응답. 2025·2026학년도. 첫 행은 한글 열 이름 |
| `초등학교시간표.json` | NEIS 초등학교시간표 응답. 2026-2학기, 10,000행(1회 응답 한도에서 잘림). 첫 행은 한글 열 이름, 과목이 빈 행은 토요일·휴일 자리표시 |
| `*_오픈API명세서.xls` | NEIS API 명세 |

정규화 규칙(2026학년도만, 빈 행 제거, 개발에는 9월분만 사용)은 `docs/architecture.md` §4.6에 있다.

## db/서울개포초등학교

| 파일 | 내용 | 화면 |
|---|---|---|
| `층배치.json` | 층 수, 반·특수학급·특별실의 층. **임의로 만든 값이며 실제 배치가 아니다** | ③ 학급·층 |
| `특수학급시간표.json` | K1·K2의 요일·시각별 과목(매주 반복). 학생은 그 요일·시각에 자기 과목을 하는 특수학급으로 간다(D25). **임의로 만든 값** | ③ 특수학급 시간표 |
| `학생.json` | 학생 7명(S01–S07, 모두 다른 반), 소속 반, `special_class_subjects`(특수학급에서 듣는 과목 목록. 지금은 국어·수학. 장소는 특수학급 시간표로 정함, 소속 특수학급 없음), `support_subjects`(원반 수업에서 지원이 필요한 과목과 지원 구간, 지금은 과학·영어·음악). 둘 다에 있는 과목은 특수학급 수업이 우선 | ④ 학생, ⑥ 배치 |
| `지원인력.json` | 지원인력 3명(A01–A03), 근무 시간(모두 풀타임: 월~금 08:40–16:40으로 가정) | ⑧ 지원인력 |

`label`은 별칭이다. **실명은 어떤 파일에도 쓰지 않는다**(`docs/architecture.md` §5).
