# M? 보드

> 버전: v1 (`tasks/M?-<이름>.md`)
> 갱신: YYYY-MM-DD

이 파일은 M? 에이전트가 고친다. 끝날 때마다 갱신한다(완료 검사가 확인함).
사람은 `pnpm board`로 모든 모듈 보드를 모아 본다. "다음에 할 것"은 제안이고, 사람이 `tasks/BACKLOG.md`로 옮겨야 다음 버전 지시서가 된다.

## 이번 버전
지시서의 완료 조건을 그대로 옮기고, 끝낸 것에 체크한다. 숫자가 있으면 적는다.
- [ ] 완료 조건 1
- [x] 완료 조건 2 — 결과: …

## 다음에 할 것 (제안)
하다가 발견한 다음 일. 한 줄에 하나, 왜 필요한지 짧게.
- 제안 — 이유

## 다른 모듈에 필요한 것
다른 모듈이나 계약(M0)이 해 줘야 하는 일. 계약 변경이면 요청 파일 경로를 적는다.
- M? — 무엇 (contracts/requests/…)
